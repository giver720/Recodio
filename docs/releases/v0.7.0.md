# Boost de audio en Recodio

Recodio 0.7.0 incorpora amplificación adicional al reproductor interno, basada en
el sistema Audio Boost de Vortex.

## Audio Boost

- Ganancia regulable entre 0 y +15 dB para música y vídeo.
- Volumen normal y amplificación adicional funcionan como controles independientes.
- Protección de picos activada por defecto para reducir clipping y distorsión.
- Los ajustes se conservan entre sesiones.
- La ventana flotante recibe y aplica la misma configuración en tiempo real.
- El procesamiento es reversible y no modifica los archivos descargados.

## Instalación

**Windows** — descarga `Recodio_0.7.0_x64-setup.exe`.

**Debian, Ubuntu y derivadas**

```bash
sudo apt install ./Recodio_0.7.0_amd64.deb
```

**Cualquier distribución Linux**

```bash
chmod +x Recodio_0.7.0_amd64.AppImage
./Recodio_0.7.0_amd64.AppImage
```

También puedes actualizar desde **Ajustes › Actualizaciones**.
