# Audio Pro completo en Recodio

Recodio 0.8.0 sustituye el boost básico por una suite de procesamiento de audio
en tiempo real para el reproductor interno, sin modificar los archivos.

## Audio Pro

- Modos Personal, Seguro, Potente, Noche y Voz.
- Ecualizador interactivo de 10 bandas, desde 31 Hz hasta 16 kHz y recorrido de
  ±12 dB.
- 16 presets: Plano, Rock, Pop, Electrónica, Urbano, Acústico, Clásica, Graves,
  Agudos, Sonrisa, Voz, Noche, Cine, TV, Juegos y Podcast.
- Boost de hasta +15 dB, realce de graves y control de claridad.
- Protección de picos mediante limitador dinámico.
- Diagnóstico en tiempo real de la señal antes y después del limitador.
- Comparación instantánea entre tono original y sonido procesado.
- Acceso rápido desde el reproductor normal, la vista ampliada y la ventana
  flotante.
- Sincronización inmediata de ajustes y mediciones con la ventana flotante.
- Migración automática de los ajustes de boost de Recodio 0.7.0.
- Reproducción normal y aviso claro cuando Web Audio no está disponible.

## Instalación

**Windows** — descarga `Recodio_0.8.0_x64-setup.exe`.

**Debian, Ubuntu y derivadas**

```bash
sudo apt install ./Recodio_0.8.0_amd64.deb
```

**Cualquier distribución Linux**

```bash
chmod +x Recodio_0.8.0_amd64.AppImage
./Recodio_0.8.0_amd64.AppImage
```

También puedes actualizar desde **Ajustes › Actualizaciones**.
